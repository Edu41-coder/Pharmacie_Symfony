N'oubliez pas d'installer le bundle KnpPaginatorBundle si ce n'est pas déjà fait :

composer require knplabs/knp-paginator-bundle

D'abord, modifions le contrôleur pour gérer le tri et la pagination :

Ajoutons la pagination en bas du tableau :
<div class="navigation d-flex justify-content-center">
+                     {{ knp_pagination_render(pagination, null, {}, {
+                         'align': 'center',
+                         'size': 'small',
+                         'rounded': true
+                     }) }}
+                 </div>
