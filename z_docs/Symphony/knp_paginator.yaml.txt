Oui, c'est toujours mieux d'avoir ce fichier de configuration knp_paginator.yaml car :
Il définit les paramètres essentiels pour le fonctionnement du paginateur :
page_range: 5 : Définit combien de numéros de page sont visibles
page_name: page : Définit le nom du paramètre dans l'URL pour la pagination
sort_field_name: sort et sort_direction_name: direction : Définissent les noms des paramètres pour le tri
Sans cette configuration :
Le bundle utiliserait des valeurs par défaut qui pourraient ne pas correspondre à vos besoins
Les paramètres d'URL pourraient être différents de ceux attendus dans vos contrôleurs
Le nombre de pages affichées pourrait être inadapté
C'est une bonne pratique de :
Avoir une configuration explicite
Centraliser les paramètres de pagination
Maintenir la cohérence entre tous les contrôleurs
La configuration actuelle est minimale mais suffisante pour votre cas d'utilisation, puisque nous utilisons notre propre template de pagination.

knp_paginator:
    page_range: 5                      # nombre de pages à afficher
    default_options:
        page_name: page                # nom du paramètre de page
        sort_field_name: sort          # nom du paramètre de tri
        sort_direction_name: direction # nom du paramètre de direction
        distinct: true                 # s'assurer que les résultats sont uniques
