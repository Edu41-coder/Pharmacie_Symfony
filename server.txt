Sur PowerShell, vous pouvez exécuter PHPUnit de plusieurs façons :

PS C:\xampp\htdocs\Pharmacie> .\vendor\bin\phpunit

PS C:\xampp\htdocs\Pharmacie> php vendor/bin/phpunit

Ou créer un script dans composer.json :
PS C:\xampp\htdocs\Pharmacie> composer test


Vous pouvez aussi ajouter des options :

# Exécuter un fichier de test spécifique
PS C:\xampp\htdocs\Pharmacie> .\vendor\bin\phpunit tests/Core/Router/RouterTest.php

# Avec couleurs et verbose
PS C:\xampp\htdocs\Pharmacie> .\vendor\bin\phpunit --colors=always --verbose

# Avec un filtre
PS C:\xampp\htdocs\Pharmacie> .\vendor\bin\phpunit --filter testParseUrl

# Tester un fichier spécifique
.\vendor\bin\phpunit tests/Core/Router/RouterTest.php

# Tester une classe spécifique
.\vendor\bin\phpunit --filter RouterTest

# Afficher la couverture de code
.\vendor\bin\phpunit --coverage-text

Ah, il y a une confusion ici. Vous pouvez accéder à l'application même avec symfony server:stop --all car votre application tourne en réalité sur Apache (XAMPP) et non sur le serveur Symfony.
Il y a deux façons différentes de faire tourner une application Symfony :
Avec le serveur de développement Symfony :
symfony server:start
# Utilise généralement le port 8000

Avec Apache (XAMPP) :
# Configuré dans votre httpd.conf et vhosts
# Tourne sur le port que vous avez configuré (8000 dans votre cas)

Dans votre cas, c'est Apache qui sert votre application, pas le serveur de développement Symfony. C'est pourquoi :
symfony server:stop --all n'a pas d'effet
L'application reste accessible via Apache
Pour vraiment arrêter votre application, il faut :
Arrêter Apache dans XAMPP Control Panel
Ou utiliser la commande : net stop Apache2.4 (en admin)
Si vous voulez utiliser exclusivement le serveur de développement Symfony :
Arrêtez Apache dans XAMPP
Utilisez symfony server:start
Pour l'arrêter, utilisez symfony server:stop
Le serveur de développement Symfony est utile pour le développement, mais en production, on utilise toujours un vrai serveur web comme Apache ou Nginx.
